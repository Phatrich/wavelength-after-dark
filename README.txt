WAVELENGTH: AFTER DARK — FREE OFFLINE-CAPABLE PWA

Included: index.html, cards.json (250 starter spectra), service worker, manifest and app icons.

FREE INSTALL STEPS:
1. Create a free GitHub account and a new public repository named wavelength-after-dark.
2. Upload the contents of this ZIP to the repository root.
3. Repository Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Open the published HTTPS address in Safari on iPhone while online.
5. Tap Share → Add to Home Screen.
6. Launch from the Home Screen. After its first successful online load, it works offline.

Manage cards to add/edit/delete, filter and search. Export backup regularly. Import replaces the current collection. Cards are stored in this browser on this device.

Unofficial fan-made companion, not affiliated with the creators or publisher of Wavelength.
